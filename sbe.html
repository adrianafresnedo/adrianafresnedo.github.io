Synxis Booking Engine

The Synxis Booking Engine is a highly customizable web application that allows global hotel chains —from luxury resorts to boutique B&Bs— to integrate a seamless booking experience into their own websites.

Project Overview

Prior to the launch of the new SBE, the platform required a critical frontend refactor to resolve performance bottlenecks and styling inconsistencies. Although I was no longer an active member of the core development team at the time, I stepped in to lead this high-pressure initiative, successfully delivering a complete overhaul within a strict 30-day window.

  • Role: Frontend Developer & Designer
  • Technologies: HTML, Sass, JSON, React
  • Duration: 1 month
  • Year: 2014

The Challenge

The legacy codebase faced three primary hurdles:

  1. Technical Debt: Code required deep cleaning for modern syntax and performance optimization.
  2. Rigid Theming: The existing system lacked the flexibility needed for diverse hotel branding.
  3. Visual Inconsistency: The user experience was fragmented across different modules.

My Approach & Key Contributions

  1. Component Architecture: Reworked all common components and core screens to improve UX and build a cohesive Design System based on company standards.
  2. Dynamic Theming Engine: Redesigned the JSON-based configuration file to maximize flexibility for hotel clients while ensuring future scalability.
  3. CSS Architecture: Rewrote the styling layer using Sass, establishing a robust framework for layouts, spacing, and structural rules.
  4. Documentation & Mentorship: Authored comprehensive guides for the design system and CSS usage, providing the development team with a long-term reference for maintainability.
