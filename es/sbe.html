Synxis Booking Engine

El Synxis Booking Engine (SBE) es una aplicación web altamente personalizable que permite a las cadenas hoteleras —desde resorts de lujo hasta Bed & Breakfast boutique— integrar una experiencia de reserva fluida directamente en sus propios sitios web.

Descripción del proyecto

Antes del lanzamiento del nuevo SBE, la plataforma requería una refactorización crítica del frontend para resolver cuellos de botella de rendimiento e inconsistencias de estilo. Aunque en ese momento yo ya no era un miembro activo del equipo de desarrollo principal, intervine para liderar esta iniciativa de alta presión, logrando una renovación completa en un plazo estricto de 30 días.

  • Rol: Diseñadora y Desarrolladora Frontend
  • Tecnologías: HTML, Sass, JSON, React
  • Duración: 1 mes
  • Año: 2014

El desafío

El código heredado (legacy) enfrentaba tres obstáculos principales:

  1. Deuda Técnica: El código requería una limpieza profunda para adaptarse a la sintaxis moderna y optimizar el rendimiento.
  2. Tematización Rígida: El sistema existente carecía de la flexibilidad necesaria para las diversas identidades de marca de los hoteles.
  3. Inconsistencia Visual: La experiencia del usuario estaba fragmentada en los diferentes módulos.

Mi Enfoque y Contribuciones Clave

  1. Arquitectura de Componentes: Rediseñé todos los componentes comunes y las pantallas principales para mejorar la experiencia de usuario (UX) y construir un Sistema de Diseño cohesivo basado en los estándares de la compañía.
  2. Motor de Tematización Dinámico: Rediseñé el archivo de configuración basado en JSON para maximizar la flexibilidad de los clientes hoteleros, garantizando al mismo tiempo la escalabilidad futura.
  3. Arquitectura CSS: Reescribí la capa de estilos utilizando Sass, estableciendo un marco robusto para diseños (layouts), espaciado y reglas estructurales.
  4. Documentación y Mentoría: Elaboré guías completas sobre el sistema de diseño y el uso de CSS, proporcionando al equipo de desarrollo una referencia a largo plazo para el mantenimiento del sistema.
